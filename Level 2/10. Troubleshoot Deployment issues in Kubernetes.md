# Troubleshoot Deployment issues in Kubernetes

Last week, the Nautilus DevOps team deployed a redis app on Kubernetes cluster, which was working fine so far. This morning one of the team members was making some changes in this existing setup, but he made some mistakes and the app went down. We need to fix this as soon as possible. Please take a look.


The deployment name is `redis-deployment`. The pods are not in running state right now, so please look into the issue and fix the same.

`redis:alpin` → Image does not exist → ImagePull error

`redis-conig` → ConfigMap not found → Volume mount failure

Pod stuck in `ContainerCreating`


## Step 1: Fix the Image name and ConfigMap name

```sh
kubectl edit deployment redis-deployment
```

<h3 align='center'>For image</h3>

**Find this:**

```yaml
image: redis:alpin
```

**Change to:**

```yaml
image: redis:alpine
```

<h3 align='center'>For ConfigMap</h3>

**Find this:**

```yaml
configMap:
  name: redis-conig
```

**Change to:**

```yaml
configMap:
  name: redis-config
```

## Step 2: Check rollout status

```sh
kubectl rollout status deployment/redis-deployment
kubectl get pods
```
